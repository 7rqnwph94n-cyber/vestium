# External Evidence Providers (Official Docs)

- OpenAlex API docs: https://docs.openalex.org/how-to-use-the-api/rate-limits-and-authentication
- Crossref REST API auth/access: https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/
- Semantic Scholar API: https://www.semanticscholar.org/product/api
- NVD API key request: https://nvd.nist.gov/developers/request-an-api-key
- NVD developer start: https://nvd.nist.gov/developers/start-here
- openFDA auth/limits: https://open.fda.gov/apis/authentication/
- Google Fact Check Tools API: https://developers.google.com/fact-check/tools/api
- Unsplash API docs: https://unsplash.com/documentation
- Pexels API docs: https://www.pexels.com/api/documentation/
- Pixabay API docs: https://pixabay.com/api/docs/

- `VITE_OPENALEX_API_KEY`
- `VITE_SEMANTICSCHOLAR_API_KEY`
- `VITE_NVD_API_KEY`
- `VITE_OPENFDA_API_KEY`
- `VITE_GOOGLE_FACTCHECK_API_KEY`
- `VITE_UNSPLASH_API_KEY`
- `VITE_PEXELS_API_KEY`
